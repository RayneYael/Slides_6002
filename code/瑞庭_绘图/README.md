# Code directory policy

This folder is the single location for source code used by this project.

- Put all newly created Python, PowerShell, JavaScript, and other source or build scripts under `code/`.
- Use `code/scripts/` for runnable workflows, `code/utils/` for shared modules, and `code/aux/` for code-side supporting assets.
- Put temporary build or QA code under `code/_cleanup_archive_20260827/` when it must be retained.
- Do not place new source scripts inside the data, PowerPoint, figure, or final-result folders.
- Final deliverables such as `.pptx` or user-facing `.html` files may remain in their corresponding assignment-section folders.
