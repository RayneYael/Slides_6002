# CO₂ 数据合并与预处理方案

> **项目**：CA6002 Data Visual Assignment — 全球国家 CO₂ 排放模式分析  
> **版本**：v1.0  
> **日期**：2026-08-17  
> **适用范围**：时域分析（Group A）、空域/结构分析（Group B）、聚类建模（Group C/D）

---

## 1. 方案概述

本方案将 **Our World in Data (OWID)** 主数据集与 **Kaggle Global Carbon Budget 2022 (GCB)** 补充数据集合并，生成组内统一的分析底表。

**核心思路**：

- **OWID** 作为主数据源：提供国家面板、`co2` 总量、人均、人口、增长率，以及 2022–2024 最新年份；
- **GCB 2022** 作为补充源：填补 OWID 中 `coal_co2` / `gas_co2` 的结构性缺失（本质上是将 OWID 留空的 **0 值** 补回）；
- 合并后采用 **双时间窗口**：时域趋势用长窗口，燃料结构/聚类用短窗口。

**一句话**：OWID 为主，GCB 补煤/气分项；1995–2024 做趋势，1995–2021 做结构。

## 3. 为什么要合并？

### 3.1 OWID 的煤/气缺失是结构性的

在 **1995–2024、国家级** 窗口下：

| 列 | OWID 缺失率 | 原因 |
|----|------------|------|
| `co2` | 1.4% | 极少缺失 |
| `oil_co2` | 2.2% | 几乎完整 |
| `coal_co2` | **37.5%** | OWID 未展开，非源数据不存在 |
| `gas_co2` | **43.3%** | 同上 |

- 65 国 30 年完全没有 `coal_co2`
- 80 国 30 年完全没有 `gas_co2`
- 三者齐全（coal + oil + gas）仅 **49.6%** 行

### 3.2 GCB 可高效补缺口

| 指标 | 数值 |
|------|------|
| GCB 1995–2021 coal/gas 覆盖率 | ~**97%** |
| 可填补 OWID coal 缺失 | **87.1%**（2,081 / 2,390 行） |
| 可填补 OWID gas 缺失 | **87.9%**（2,437 / 2,771 行） |
| 可填补的值 | **全部为 0**（零煤/零气国家） |

### 3.3 重叠样本数值一致性高

1995–2021 两表均有值的样本对比：

| 指标 | 重叠行数 | Pearson r | 中位相对差 | <0.5 Mt 占比 |
|------|----------|-----------|------------|--------------|
| 总排放 | 5,832 | 0.99997 | 0.59% | 74% |
| coal | 3,676 | 0.99997 | 0.13% | 87% |
| oil | 5,757 | 0.99974 | 0.19% | 86% |
| gas | 3,320 | 0.99974 | 0.03% | 88% |

差异主要来自 **GCB 版本不同**（2022 vs 2025），大国近年绝对差稍大但相对差通常 < 3%。

**结论：可以合并，且合并风险低。**

## 4. 时间窗口策略（双窗口）

由于 GCB 只到 **2021**，而 OWID 到 **2024**，采用双窗口：

| 窗口 | 年份 | 用途 | 燃料结构完整度（合并后） |
|------|------|------|--------------------------|
| **长窗口** | 1995 – **2024** | 时域趋势、全球/国家总量变化 | coal/gas ~**95%** 完整；2022–2024 仍缺煤/气 |
| **短窗口** | 1995 – **2021** | 燃料结构、空域对比、聚类特征 | 三燃料 ~**98.7%** 完整 |

### 4.1 各组使用建议

| 组别 | 任务 | 推荐窗口 | 主要字段 |
|------|------|----------|----------|
| A | 时域分析 | **1995–2024** | `co2`, `co2_per_capita`, `co2_growth_*` |
| B | 空域/结构 | **1995–2021** | `coal_co2_filled`, `oil_co2`, `gas_co2_filled`, 占比 |
| C | 聚类特征 | **1995–2021** | 规模、人均、燃料占比、趋势斜率 |
| D | 聚类评估 | 同 C | 同 C |

> 若 Group A 需要展示 2022–2024 趋势，仍可用长窗口；Group B/C 涉及 coal/gas 结构时应明确标注「1995–2021」。

## 5. 合并规则

### 5.1 合并键

```
iso_code + year
```

- 优先用 ISO 匹配，不用国名（避免 Spelling 差异）
- 合并方式：**左连接**（以 OWID 为主表，保留 OWID 全部国家-年份行）

### 5.2 填补规则（仅 coal / gas）

对以下字段执行 **条件填补**：

```python
coal_co2_filled = coal_co2  if not NA  else  gcb_coal
gas_co2_filled  = gas_co2   if not NA  else  gcb_gas
```

**硬性约束**：

| 规则 | 说明 |
|------|------|
| ✅ 只填 NA | OWID 已有值 **绝不覆盖** |
| ✅ 只填 coal/gas | `co2`、`oil_co2`、`co2_per_capita` 等保持 OWID 原值 |
| ✅ 保留来源标记 | 新增 `coal_source` / `gas_source` 列（`owid` / `gcb` / `missing`） |
| ❌ 不用 GCB 覆盖 oil | OWID 的 `oil_co2` 已 97.8% 完整，无需替换 |
| ❌ 不用 GCB 覆盖 co2 总量 | 避免版本混用；总量统一 OWID（GCB 2025） |

### 5.3 合并后衍生字段

在填补完成后计算（仅 `coal_co2_filled`、`oil_co2`、`gas_co2_filled` 均非空时）：

```
fuel_total     = coal_co2_filled + oil_co2 + gas_co2_filled
coal_share     = coal_co2_filled / fuel_total
oil_share      = oil_co2 / fuel_total
gas_share      = gas_co2_filled / fuel_total
```

可选（Group C 聚类用）：

```
co2_trend_slope    = 1995–2021 co2 对 year 的 OLS 斜率（按国家）
co2_per_capita_mean = 1995–2021 co2_per_capita 均值
co2_level_2021     = 2021 年 co2（或 2021 年 co2_per_capita）
```

## 6. 预处理流水线

### Step 0：读取与列重命名

```
输入：
  - owid-co2-data.csv
  - GCB2022v27_MtCO2_flat.csv

GCB 重命名：
  ISO 3166-1 alpha-3 → iso_code
  Year              → year
  Coal              → gcb_coal
  Oil               → gcb_oil
  Gas               → gcb_gas
  Total             → gcb_total
  Cement            → gcb_cement
  Flaring           → gcb_flaring
```

### Step 1：时间筛选

```
保留 year >= 1995 AND year <= 2024
```

### Step 2：实体筛选

```
保留条件：iso_code IS NOT NULL
排除：36 个聚合实体（World, Africa, Asia, Europe, EU, 收入组, International aviation/shipping 等）
```

**排除判断**：`iso_code` 为空即为聚合实体，无需维护额外黑名单。

### Step 3：剔除无效国家

以下 3 国在 1995–2024 全程无 `co2`，直接剔除：

- Monaco (`MCO`)
- San Marino (`SMR`)
- Vatican (`VAT`)

### Step 4：左连接 GCB

```
OWID (filtered) LEFT JOIN GCB
  ON iso_code = iso_code AND year = year
```

预期匹配：1995–2021 约 87.7% 行能关联到 GCB；2022–2024 GCB 列为 NA（正常）。

### Step 5：条件填补 coal / gas

```
IF coal_co2 IS NULL AND gcb_coal IS NOT NULL:
    coal_co2_filled = gcb_coal
    coal_source = 'gcb'
ELIF coal_co2 IS NOT NULL:
    coal_co2_filled = coal_co2
    coal_source = 'owid'
ELSE:
    coal_co2_filled = NULL
    coal_source = 'missing'

（gas 同理）
```

### Step 6：删除核心缺失行

```
删除 co2 IS NULL  OR  population IS NULL  OR  co2_per_capita IS NULL 的行
```

### Step 7：标记特殊国家（不删除）

新增标记列：

| 列名 | 规则 | 用途 |
|------|------|------|
| `is_micro_state` | 2021 年 `population` < 50,000 | 聚类/地图时可选排除 |
| `is_high_per_capita` | 2021 年 `co2_per_capita` > 20 t/person | 解释型 outlier |
| `fuel_complete` | coal_filled & oil & gas 均非空 | 结构分析筛选 |

### Step 8：计算燃料占比

```
仅 fuel_complete = True 的行计算 coal_share / oil_share / gas_share
```

### Step 9：输出文件

见第 7 节。

### Step 10：质量报告

输出 `merge_qa_report.json`，记录各步骤行数变化与缺失率（见第 8 节）。

| `gdp` / `co2_per_gdp` | 缺失 25–30%，已有 `co2_per_capita` |

> 20 个国家/地区 2021 年人口 < 5 万，人均排放指标波动大。已在数据中标记 `is_micro_state`，聚类时可设人口下限（如 ≥ 10 万）作敏感性分析。

## 11. 预处理伪代码（Python 参考）

```python
import pandas as pd
from pathlib import Path

ROOT = Path("data")
owid = pd.read_csv(ROOT / "co2-data-master/co2-data-master/owid-co2-data.csv")
gcb = pd.read_csv(ROOT / "archive_kaggle/GCB2022v27_MtCO2_flat.csv")

gcb = gcb.rename(columns={
    "ISO 3166-1 alpha-3": "iso_code",
    "Year": "year",
    "Coal": "gcb_coal",
    "Gas": "gcb_gas",
})

# Step 1-2: filter
df = owid[(owid.year >= 1995) & (owid.year <= 2024) & owid.iso_code.notna()].copy()

# Step 3: drop invalid countries
drop = {"Monaco", "San Marino", "Vatican"}
df = df[~df.country.isin(drop)]

# Step 4: merge
df = df.merge(gcb[["iso_code", "year", "gcb_coal", "gcb_gas"]], on=["iso_code", "year"], how="left")

# Step 5: fill coal/gas
def fill_col(owid_col, gcb_col):
    filled = df[owid_col].copy()
    source = pd.Series("missing", index=df.index)
    has_owid = df[owid_col].notna()
    filled[has_owid] = df.loc[has_owid, owid_col]
    source[has_owid] = "owid"
    can_fill = df[owid_col].isna() & df[gcb_col].notna()
    filled[can_fill] = df.loc[can_fill, gcb_col]
    source[can_fill] = "gcb"
    return filled, source

df["coal_co2_filled"], df["coal_source"] = fill_col("coal_co2", "gcb_coal")
df["gas_co2_filled"], df["gas_source"] = fill_col("gas_co2", "gcb_gas")

# Step 6: drop core missing
core_cols = ["co2", "population", "co2_per_capita"]
df = df.dropna(subset=core_cols)

# Step 7: flags
pop_2021 = df[df.year == 2021].set_index("iso_code")["population"]
micro_iso = set(pop_2021[pop_2021 < 50000].index)
df["is_micro_state"] = df.iso_code.isin(micro_iso)

pc_2021 = df[df.year == 2021].set_index("iso_code")["co2_per_capita"]
high_iso = set(pc_2021[pc_2021 > 20].index)
df["is_high_per_capita"] = df.iso_code.isin(high_iso)

# Step 8: fuel shares
df["fuel_complete"] = df[["coal_co2_filled", "oil_co2", "gas_co2_filled"]].notna().all(axis=1)
fuel_total = df["coal_co2_filled"] + df["oil_co2"] + df["gas_co2_filled"]
df.loc[df.fuel_complete, "coal_share"] = df.loc[df.fuel_complete, "coal_co2_filled"] / fuel_total[df.fuel_complete]
df.loc[df.fuel_complete, "oil_share"]  = df.loc[df.fuel_complete, "oil_co2"] / fuel_total[df.fuel_complete]
df.loc[df.fuel_complete, "gas_share"]  = df.loc[df.fuel_complete, "gas_co2_filled"] / fuel_total[df.fuel_complete]

# Step 9: export
out = ROOT / "processed"
out.mkdir(exist_ok=True)
cols = [
    "country", "iso_code", "year", "population",
    "co2", "co2_per_capita", "co2_growth_abs", "co2_growth_prct",
    "oil_co2", "coal_co2", "gas_co2",
```
