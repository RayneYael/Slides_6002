# Initialize presentation workstreams

## Goal

Initialize the course-assignment repository with three clearly separated workstream directories so five collaborators can organize their HTML presentation work by topic.

## Background

- The assignment brief is stored at `docs/CA6002 Assignment Brief - 07Jul2026.pdf`.
- The repository will integrate work from five people across three presentation directions.

## Requirements

- Create a top-level `dataset-analysis/` directory for dataset analysis materials.
- Create a top-level `model-analysis/` directory for model and analysis materials.
- Create a top-level `storytelling/` directory for storytelling materials.
- Keep this initialization limited to the directory structure; do not create presentation files or interpret the assignment brief yet.

## Acceptance Criteria

- [x] `dataset-analysis/` exists at the repository root.
- [x] `model-analysis/` exists at the repository root.
- [x] `storytelling/` exists at the repository root.
- [x] Git can track each new directory through a minimal placeholder file.

## Out of Scope

- Creating or editing HTML slides.
- Assigning collaborators to workstreams.
- Analyzing or summarizing the assignment PDF.
